# Hot Off The Press Jamaica — Redesign Concept Demo

A presentation-ready redesign concept for **Hot Off The Press Jamaica (HOTP)**.

## Purpose

This repository is a standalone design/demo environment. It does **not** replace or modify the current production website at hotpjamaica.com.

## Included

- Premium responsive homepage
- Service discovery grid
- Filterable portfolio concept
- About / production-capacity section
- 2025 price-guide CTA
- Interactive front-end quote builder
- Artwork-upload UI concept
- Mobile navigation and sticky mobile quote CTA
- Accessible focus states and responsive layouts
- CMYK-inspired visual system

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static server.

## Deployment

This demo has no build step and can be deployed directly to GitHub Pages, Cloudflare Pages, Netlify or Vercel as a static site.

## Notes

Pricing generated by the quote UI is intentionally **not authoritative**. The demo scopes a job and indicates that HOTP must confirm the actual price.

Business information is based on publicly available HOTP Jamaica information and is intended for redesign presentation purposes.
